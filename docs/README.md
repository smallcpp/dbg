# docs

This directory holds the documents for dbg.

[debugger.md](debugger.md) explains what the debugger does and how to build, install, and run it.

[limits.md](limits.md) lists cdbg behavior that this debugger does not match.

[coding-standard.md](coding-standard.md) is the smallcpp coding standard.

[CHANGELOG.md](CHANGELOG.md) records what the test suite gained.

The compiler is in the [smallcpp](https://github.com/smallcpp/smallcpp) repository.
